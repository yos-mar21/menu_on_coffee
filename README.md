# ON COFFEE · Menú digital

Menú web adaptable a celular, pensado para abrirse desde una etiqueta NFC.

## Archivos

- `index.html`: contenido y categorías del menú.
- `styles.css`: diseño, paleta y adaptación móvil.
- `on-icon-sage.png`: símbolo oficial adaptado a la paleta del local.

Para actualizar el menú, edita los productos y precios directamente en `index.html`.

Antes de programar las etiquetas NFC, publica este repositorio como sitio web y copia la URL pública en cada etiqueta.
